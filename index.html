About this map

This map lists the churches and prayer houses of the True Jesus Church (Gereja Yesus Benar) in Sabah, Labuan and Sarawak. Each mapped location has a KodLokasi code. Tap the code to open directions in the KodLokasi app or web app, which hands over to Google Maps or Waze.

Data sources

Names, addresses, service times and coordinates: church subzone documents (November 2026). Kuching and Miri: OpenStreetMap contributors. KodLokasi codes: KodLokasi web app (map.kodlokasi.my) for the coordinates shown. Base maps: satellite imagery © Esri, Maxar, Earthstar Geographics; street map © OpenStreetMap contributors. District boundaries: geoBoundaries (CC BY 3.0), simplified and indicative only. Data download: tjc_locations.geojson.
